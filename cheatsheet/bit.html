bit 全探索

各要素を「選ぶ・選ばない」の 2 通りに分けて、すべての組合せを調べます。Python では range(1 << n) と bit & (1 << i) が基本形です。

  5. 計算量と注意点
  • 要素が n 個なら、選び方は空集合を含めて 2ⁿ 通りです。
  • 右端のビットが、添字 0 の要素に対応します。
  • 各選び方で n 個の要素を確認する基本形の計算量は O(n × 2ⁿ) です。

使う場面と仕組み

bit（ビット）は 0 または 1 の値です。bit 全探索は、各ビットを要素の選択状態として使う全探索です。ビットが 1 ならその要素を選び、0 なら選びません。選択状態をまとめた整数を、ここでは bit と呼びます。

この方法は、少数の品物から条件に合う組合せを探す問題で使えます。選ぶ順序は区別せず、各要素は最大 1 回だけ選びます。

基本形

a = [3, 4, 7]
n = len(a)

# すべての選択状態を列挙する
for bit in range(1 << n):
    selected = []
    for i in range(n):
        # i 番目のビットが 1 なら、その要素を選ぶ
        if bit & (1 << i):
            selected.append(a[i])
    print(f"{bit:0{n}b}", selected)
実行結果を確認する

001 [3]
010 [4]

1 << n は 2ⁿ です。range の終端は含まれないため、bit は 0 から 2ⁿ − 1 まで動きます。bit & (1 << i) はビットが立っていれば 0 以外になります。Python の if は、その値を真として扱います。

実例：部分和を調べる

配列から要素を選び、合計を 10 にできるか調べます。各要素は最大 1 回だけ使えます。答えが見つかったら、外側のループを終了します。

a = [3, 4, 7]
target = 10
n = len(a)
found = False

# 選んだ要素の合計を求める
for bit in range(1 << n):
    total = 0
    for i in range(n):
        if bit & (1 << i):
            total += a[i]

    # 条件を満たす選び方が見つかったら探索を終える
    if total == target:
        found = True
        break

print("Yes" if found else "No")  # Yes（3 + 7 = 10）

合計だけを使う場合は、選んだ要素のリストを作る必要はありません。負の値が含まれていても、この全探索は動作します。

計算量と注意点

基本形は 2ⁿ 通りそれぞれで n 個の要素を確認します。時間計算量は O(n × 2ⁿ)、選んだ要素を格納する追加の記憶量は O(n) です。部分和の例のように合計だけを保持する場合、追加の記憶量は O(1) です。これらは整数演算を定数時間とみなした目安です。

n = 20 付近でも、Python の実行時間は内側の処理と制限時間に左右されます。n が 1 増えるだけで選び方は 2 倍になるため、制約から実行可能性を判断します。

  • 判定式を 1 と比較しません。 bit & (1 << i) の結果は、選択時に 1、2、4 などになります。
  • 空集合の合計は 0 です。 target が 0 の場合、部分和の例は空集合でも Yes になります。1 個以上選ぶ条件がある場合は bit = 0 を除きます。
  • 同じ値でも添字が違えば別の要素です。 [3, 3] には 4 通りの選び方があります。値の一覧としては同じ結果が現れます。
  • n = 0 の場合も 1 通りです。 range(1 << 0) は bit = 0 だけを列挙します。
  • 用途に応じて列挙方法を選びます。 個数を k 個に固定するなら itertools.combinations、順序を区別するなら itertools.permutations、各要素に 3 通り以上の選択肢があるなら itertools.product も候補になります。
